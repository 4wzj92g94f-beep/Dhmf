# KOMARU SHOP — переработанный игровой прототип

## Что реализовано
- Начальная заставка с Мяовл и Комару.
- Отдельная сцена магазина с дверью, витринами, полками, кассой и продавцом.
- Магазин изначально закрыт: игрок сам начинает рабочий день.
- Стартовый ассортимент ограничен двумя значками: Мяовл и Комару, по 100 ₸.
- Покупатели не появляются до открытия рабочего дня и нажатия «Позвать покупателя».
- Диалоги с несколькими вариантами ответа, выбором товара, рассказом о персонаже, продажей и скидкой.
- Анимации входа покупателей, движения продавца, рулетки и заставки.
- Баланс, репутация, остатки товаров, число посетителей и продаж сохраняются в localStorage.

## Запуск и публикация
Для GitHub Pages распакуйте архив и загрузите **содержимое папки `komaru_shop`** в корень репозитория. В корне должны быть `index.html`, `style.css`, `js/` и `assets/`.
В настройках репозитория: Settings → Pages → Deploy from a branch → main → /(root).

## Важно
Мяовл и Комару нарисованы как отдельные персонажи на основе предоставленных пользователем референсов. Это игровая стилизация, не фотографические вырезки. Другие виды товаров намеренно не доступны на старте.
